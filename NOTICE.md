## Data

- **Place names and coordinates** in `packages/rhythm/src/places-data.js` come from [GeoNames](https://www.geonames.org), through the [all-the-cities](https://github.com/zeke/all-the-cities) package, under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The data is reduced to name, country, latitude, longitude and time zone by `scripts/generate-places.mjs`.
- **Time zones** for those places were looked up at build time with [tz-lookup](https://github.com/darkskyapp/tz-lookup) (CC0 1.0). Its boundaries come from [timezone-boundary-builder](https://github.com/evansiroky/timezone-boundary-builder), which derives them from [OpenStreetMap](https://www.openstreetmap.org/copyright) data under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). © OpenStreetMap contributors.

## Algorithms

Moon phase, season and natal-chart calculations follow Jean Meeus, *Astronomical Algorithms* (2nd edition). The web app uses [astronomia](https://github.com/commenthol/astronomia) (MIT). The Swift code is an independent implementation of the published formulas.

## Code dependencies

npm dependencies are listed in `pnpm-lock.yaml`, and Rust dependencies in `apple/AtelieraVaultCore/Cargo.lock` and `apps/studio/src-tauri/Cargo.lock`. Each keeps its own licence. The Apple app has no Swift package dependencies; its Swift binding to the Rust vault core is generated by UniFFI, which is listed in `apple/AtelieraVaultCore/Cargo.lock`.
