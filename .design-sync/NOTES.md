# design-sync notes — @studio/ui → claude.ai/design

First sync: 2026-08-21. Project: "Ateliera Design System"
(`66e2a383-4cac-49e2-b0e7-0c047929492a`). 4 storied components synced (Card,
CardEditor, SemanticMark, Inspector), all graded `match`.

## Build setup (why the config looks the way it does)

- **[GENERAL] The package ships TypeScript source, not a built dist** (`exports`
  → `./src/index.ts`, `tsc --build` runs with `noEmit`). esbuild bundles the
  source fine, but the converter's component/export discovery and prop-type
  extraction need real `.d.ts`. Fix: `cfg.buildCmd` emits declarations to
  `packages/ui/dist/` via `packages/ui/tsconfig.dts.json` (declaration-only,
  non-composite), and `packages/ui/package.json` gained
  `publishConfig.types: "dist/index.d.ts"` so `findTypesRoot`/`projectFor`
  resolve the entry there. Without `publishConfig.types` the export scan looked
  for a non-existent `packages/ui/index.d.ts` and found 0 components.
- **[GENERAL] Tokens, reset, and fonts live in `apps/studio/src/styles/`, not in
  `@studio/ui`.** The app owns the design tokens; the UI package only ships
  component CSS (which the storybook scrape picks up as `_ds_bundle.css`). So:
  - `cfg.cssEntry: dist/design-tokens.css` — a build-time file generated by
    `.design-sync/gen-design-tokens.mjs` (run from `buildCmd`) that concatenates
    `tokens.css` + `reset.css` + `typography.css`'s **variable** declarations
    (its `@font-face` blocks are stripped). Regenerated every sync from the live
    sources, so it never drifts.
  - `cfg.extraFonts: [../../apps/studio/src/styles/typography.css]` — ships the
    `@font-face` rules + woff2 (Newsreader, Hanken Grotesk, Caveat) with correct
    url()s into `fonts/`.
- **[GENERAL] The `.storybook/preview.tsx` decorator wouldn't bundle** (esbuild
  had no `.woff2` loader for the fonts its CSS imports reach). It provided the
  `.studio-app[data-theme="chamomile"]` wrapper, and **every colour token is
  scoped under `.studio-app`** — without that wrapper previews render colourless.
  Fix: `cfg.provider` → `StudioThemeRoot`, a 1-component wrapper in
  `.design-sync/preview-provider.tsx` (added via `cfg.extraEntries`) that
  reproduces `<div className="studio-app" data-theme="chamomile">`.
- **App room-page stories excluded.** The shared storybook also has
  `apps/studio` `Rooms/*` + `Onboarding/*` stories; those are app compositions
  depending on `@studio/application`/`@studio/domain`, not `@studio/ui`
  primitives, and can't bundle into a UI-only global. Excluded via `titleMap`
  entries set to `null`.
- **Inspector is an overlay** (slide-in panel, fixed position) → `[GRID_OVERFLOW]`
  → `cfg.overrides.Inspector: {cardMode: "single", primaryStory: "Full"}`.
- **SemanticMark "All Meanings"** is an owned preview
  (`.design-sync/previews/SemanticMark.tsx`) reproducing the story-local
  `.semantic-mark-preview` grid inline (that class lives in `preview.css` and
  doesn't ship).
- **Config path bases:** `cfgPath` resolves most config paths relative to
  `PKG_DIR` (`packages/ui`) — hence `dist/design-tokens.css`. `extraFonts` and
  `extraEntries` resolve against the workspace root, hence their `../../` paths.

## Re-sync risks (watch-list)

- **`buildCmd` hard-codes `apps/studio/src/styles/{tokens,reset,typography}.css`**
  (via `gen-design-tokens.mjs`) and `apps/studio/src/styles/typography.css`
  (extraFonts). If those files move/rename, the token/font shipping breaks
  silently → re-check `[TOKENS_MISSING]`/`[FONT_MISSING]` after any styles
  refactor.
- **`packages/ui/dist/` is generated + gitignored.** A fresh clone must run
  `buildCmd` before the converter (declarations + design-tokens.css). Re-run the
  `.ds-sync` dep install + `playwright install chromium` on a fresh clone.
- **4 undefined CSS vars are expected** (`--studio-type-card-title`,
  `--studio-type-page-title`, `--studio-letter-spacing-tight`,
  `--studio-reading-max`): referenced only by leaked `apps/studio` room-page CSS
  in the storybook scrape, not by any of the 4 synced components. Harmless.
  Don't chase them.
- **`[FONT_MISSING]` for Iowan Old Style / Baskerville / Bradley Hand is
  accepted:** these are system-font *fallbacks* in the display/handwritten
  stacks. The primary brand fonts (Newsreader, Hanken Grotesk, Caveat) all ship
  and render. Confirmed against the rendered previews.
- **`publishConfig.types` was added to `packages/ui/package.json`** — a real repo
  change (harmless for a private package). If it's reverted, export discovery
  regresses to 0 components.
- **Inspector story cap:** all 8 stories are captured and graded (`--max-stories 8`).
  If stories are added, they'll need re-capture.
